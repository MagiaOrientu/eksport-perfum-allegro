# Eksport Perfum Magia Orientu

## Cel aplikacji
Prywatne narzędzie przeznaczone do eksportowania danych własnych ofert sprzedażowych z konta Allegro Magia_Orient.

## Planowane działanie
Po autoryzacji właściciela konta aplikacja będzie pobierać identyfikatory ofert, tytuły, ceny, opisy oraz adresy zdjęć. Dane zostaną zapisane w pliku CSV w celu przygotowania ogłoszeń na innych platformach sprzedażowych, w tym OLX.

## Uprawnienia
allegro:api:sale:offers:read — wyłącznie odczyt danych ofert.

## Bezpieczeństwo
Aplikacja będzie używana wyłącznie przez właściciela konta. Nie będzie modyfikować ofert Allegro, pobierać danych kupujących ani publikować ofert automatycznie.

## Status
Projekt w przygotowaniu. Funkcja eksportu nie została jeszcze wdrożona.
